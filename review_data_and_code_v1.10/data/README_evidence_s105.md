# S105 source evidence

`evidence_s105.csv` retains eight historical variant-locator rows and five supporting-statement
rows prepared from the 37-page HAL v3 author manuscript (hal-01237204v3). PDF page 1 is the HAL
cover, so printed manuscript pages are PDF pages minus one. The journal pagination is not used.
Each row records the SHA-256 of the PDF read. Third-party full texts are not distributed.

Version 1.10 applies the R1 granularity rule. The seven diving configurations are one released
variant, S105-M1 (E3). The root restricted-master integer heuristic is S105-M7 (E2). The original
`method_id` and evidence identifiers remain source locators, not eight released coded variants.
`released_method_id_v1_10` maps each locator to the current inventory. S105-M7 performs no further
column generation. The scope entry corrected to E2 in version 1.9 is retained.

These are AI-assisted source checks, not independent human coding or new solver experiments.
