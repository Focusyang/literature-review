# Changes in version 1.9

Version 1.9 accompanies the submitted article. The changes below are relative to version 1.7.

* The coded inventory (`data/coded_inventory_v1_9.csv`) lists the 113 variants whose description, layers, guarantee decision and scopes are all settled under the codebook rules. GU counts as a settled guarantee decision. The inventory replaces the variant tables of earlier versions for Table A.1, Figure 3 and the counts in the article.
* The Figure 3 data were recomputed from the inventory: 58 traditional and 55 learning-guided variants with 181 variant-scope memberships. A margins file lists the variant without a measured scope.
* Figure A.1 shows the coded inventory as 113 variants from 70 families. Its discovery and screening counts are unchanged.
* Supplementary Table S1 adds the columns Canonical work ID, Count as independent work and Cited in the article. The title-level category columns and notes of version 1.7 are not part of this version.
* Supplementary Table S2 keeps the 24 families with their completion status, basis, single-instance flag and evidence record identifiers. The columns for evaluated variants, supplied upper bounds and check notes are not part of this version.
* `data/table4_source_locators_v1_9.csv` was added. It gives the source locators for every row of Table 4.
* In `data/evidence_s105.csv`, the scope entry of S105-M7 now reads E2, matching the inventory.
* The codebook and field dictionary were rewritten for the version 1.9 files. The re-coding pack was regenerated from the 113-variant inventory and contains 28 cases.
* Figures 1-3 and A.1 were redrawn with a neutral grey palette and one accent colour.
* Earlier versions, available through the concept DOI, keep their own working records and the release 1.2 tables.
